# Cryptography Algorithms: RSA & DES

---
A Python implementation of RSA (Asymmetric) and DES (Symmetric) encryption algorithms, completed as part of the CE354
Computer Security course at German Jordanian University (GJU).

## Directory Structure

The project is split into two independent modules:

```text
.
├── rsa/
│   ├── rsa_cipher.py         # Main RSA script
│   ├── primes-to-100k.txt    # Required prime number dataset
│   ├── infile.txt            # Input text for encryption/decryption
│   └── outfile.txt           # Output generated by the script
└── des/
    ├── des_cipher.py         # Main DES script (ECB Mode)
    ├── infile.txt            # Input text for encryption/decryption
    └── outfile.txt           # Output generated by the script

```

## Features & Improvements

While the foundational logic of these scripts was sourced from open-source contributors (see Credits), I made several
key modifications for this project:

* **RSA Optimization:** Drastically improved RSA execution speed (over 200k times faster) by implementing Python's
  built-in pow() function for modular exponentiation.
* **Bug Fixes:** Resolved an issue in the RSA script related to handling odd-length string inputs.
* **DES Key Generation:** Added a secure 16-character hex key generation function to the DES script.
* **Documentation:** Enhanced code readability with improved comments and execution timing decorators.

## How to Use

Both algorithms run via a command-line interface. You must navigate into the respective directory before running the
scripts.

Place the text you want to encrypt or decrypt into the infile.txt file of that directory before running the -e or -d
commands.

### RSA (Asymmetric Encryption)

Navigate to the RSA directory:

```bash
cd rsa
```

* **Generate Keys:** Randomly selects primes from primes-to-100k.txt and saves them to keys.json.

```bash
python rsa_cipher.py -g

```

* **Encrypt:** Encrypts the contents of infile.txt using the public key and writes to outfile.txt.

```bash
    python rsa_cipher.py -e
```

* **Decrypt:** Decrypts the contents of infile.txt using the private key and writes to outfile.txt.

```bash
python rsa_cipher.py -d
```

### DES (Symmetric Encryption - ECB Mode)

Navigate to the DES directory:

```bash
cd des
```

* **Generate Key:** Generates a random 16-character hex key and saves it to key.txt.

```bash
python des_cipher.py -g
```

* **Encrypt:** Pads and encrypts infile.txt using key.txt, outputting ciphertext to outfile.txt.

```bash
python des_cipher.py -e
```

* **Decrypt:** Decrypts the ciphertext from infile.txt, removes padding, and writes the plaintext to outfile.txt.

```bash
python des_cipher.py -d
```
